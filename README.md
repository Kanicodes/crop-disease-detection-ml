# Automated Multi-Crop Disease Detection Using Machine Learning

## Project Description
This project is a machine learning-based system that detects diseases in different crop leaves using image processing and a Convolutional Neural Network (CNN) model. It helps in early identification of plant diseases and supports farmers in improving crop productivity.

## Objective
To detect and classify crop diseases using leaf images and provide accurate predictions using a trained CNN model.

## Algorithm Used
Convolutional Neural Network (CNN) is used for image classification. It extracts features from crop leaf images and predicts whether the plant is healthy or diseased.

## Technologies Used
- Python  
- Machine Learning  
- Deep Learning (CNN)  
- OpenCV  
- NumPy  
- Flask  
- HTML  
- CSS  

## Working
1. User uploads crop leaf image  
2. Image is preprocessed  
3. CNN model analyzes the image  
4. Disease is predicted  
5. Result is displayed with confidence score  

## Modules
- Image Upload Module  
- Image Processing Module  
- Disease Prediction Module  
- Remedy Suggestion Module  
- Web Interface Module  

## Prediction Results
- The model predicts the crop type and disease based on the uploaded image  
- Output is displayed with prediction confidence  
- Remedies are suggested based on detected disease  

## How to Run
1. Clone the repository  
2. Install required libraries using pip  
3. Run `app.py`  
4. Open browser and upload image
